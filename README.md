# Pablo Henrique

### Engenheiro de Machine Learning em formação · IA, dados e infraestrutura

---

<p align="justify">
Acredito que um modelo só merece confiança quando sabemos de onde vêm os dados, como foi avaliado e até onde pode ser usado. Construo sistemas de ML e LLMs com esse critério.
</p>

---

### Como eu trabalho

<p align="justify">
<b>Dados primeiro.</b> Prefiro dados reais e rastreáveis. Em um trabalho da faculdade, enquanto muitos colegas geraram dados sintéticos, montei um dataset com fontes oficiais (Embrapa e IBGE) e regras explícitas.<br>
<b>Arquitetura antes do treino.</b> Defino entradas, saídas, critérios de avaliação e limites antes de escrever o modelo.<br>
<b>Métrica antes do lançamento.</b> Nenhum modelo avança sem um critério de erro definido de antemão.
</p>
